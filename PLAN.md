# Mid-Term Housing Finder — Project Plan

CS 452 Final Project · Target: ~30 hours

## Problem

Finding housing for short stays (3–6 months) is frustrating:
- Listings are scattered across Facebook Marketplace and one-off apartment complex websites.
- Short-term pricing is rarely posted. Complexes respond in one of three ways:
  1. "$X extra per month"
  2. "$Y flat fee for the whole lease"
  3. "We don't do leases that short"
- Comparing listings on *total cost of the actual stay* is nearly impossible by hand.

## Solution

A web app that collects rental listings from several sources into one SQL database, filters and
scores them against our criteria, and shows a feed where every listing has:
- **Total cost for the stay** (rent × months + short-term premium + one-time fees)
- **"+ estimated" amounts** for undisclosed costs (utilities, parking, etc.)
- **AI overview**: pros, cons, and estimates for the unspecified costs
- **Commute times** to each of our destinations

## Phase 1 scope: Utah County

- Two commute destinations: **Lehi** (daily) and **BYU campus**.
- Rank by a *balanced* commute: the **longer** of the two commutes, so neither person ends up with a long drive.
- Likely sweet spot: American Fork, Pleasant Grove, Lindon, Orem, Vineyard, Highland, Cedar Hills.
- Dallas comes later, once the Utah version works (same code, new search and sources).

## Search criteria

**Must-haves (filters)**: min/max price, cities, beds/baths, lease length, start/end dates
(± flexibility), furnished, pets, max commute per destination.

**Nice-to-haves (raise the score)**: in-unit washer/dryer, gym, pool/hot tub, parking, AC,
dishwasher, utilities included, sublet allowed, other amenities.

## Cost model

| Short-term pricing status | How total is computed |
|---|---|
| Monthly premium known | (rent + premium) × months + one-time fees |
| Flat fee known | rent × months + flat fee + one-time fees |
| Short leases refused | Shown separately: "12-month lease only" |
| Unknown | Base total + **"short-term price unknown, ask"** flag |

One-time fees = application + admin + non-refundable deposit.
Undisclosed recurring costs (utilities, parking, pet rent) are shown as "+ ~$X est.", with the
estimate generated by AI and labeled as an estimate.

**Record a quote**: after calling a complex, we enter what they said (e.g. "+$150/mo"), and the
total recalculates. This also records which listings we have contacted, without connecting
email or texts.

## Data sources (Utah)

| Source | Method |
|---|---|
| Facebook Marketplace / FB groups | **Paste a listing** (URL or text), then AI extraction. No automated scraping (requires login, blocks bots, violates terms, risks a ban). |
| Apartment complex websites | Playwright + AI extraction. Many run on shared platforms (RentCafe, Entrata, AppFolio), so one scraper can cover many complexes. |
| KSL Classifieds (rentals) | Scraper; widely used in Utah |
| Craigslist (Provo/Orem) | Scraper (simple pages) |

Avoid: Zillow and Apartments.com (strong anti-scraping measures).

## Tech stack

- **Next.js (JavaScript)**: the website and backend in one project
- **PostgreSQL on Supabase (free tier)**: SQL database, with built-in login for later
- **Playwright**: scraping
- **Claude API (small, cheap model)**: extraction, pros/cons, cost estimates. Budget under $10.
- **Commute times**: a mapping API with a free tier, called only for listings that pass the filters, with results cached in the database
- Runs locally for now; deploy to Vercel at the end

**Built to scale**: every user-owned table has a `user_id` from day one. Phase 1 uses a single
built-in user (shared by the two of us); adding sign-up later doesn't require changing the schema.

## Draft schema

```
users            (id, name, email, created_at)
searches         (id, user_id, name, start_date, end_date, date_flex_days, min_price, max_price,
                  beds_min, baths_min, furnished, pets, cities[], must_haves jsonb, nice_to_haves jsonb)
destinations     (id, search_id, label, address, lat, lng, max_minutes)
sources          (id, name, type [scraper|paste], base_url, last_run_at)
listings         (id, source_id, url, title, address, city, lat, lng, base_rent, beds, baths, sqft,
                  furnished, pets_allowed, amenities jsonb, utilities_included jsonb,
                  lease_terms jsonb, fees jsonb, raw_text, first_seen_at, last_seen_at, is_active)
price_snapshots  (id, listing_id, rent, captured_at)                -- price history
short_term_quotes(id, listing_id, user_id, type [monthly_premium|flat_fee|refused|unknown],
                  amount, lease_months, notes, quoted_at)            -- "record a quote"
commutes         (listing_id, destination_id, minutes, computed_at)
ai_summaries     (id, listing_id, search_id, pros jsonb, cons jsonb, estimated_costs jsonb,
                  model, created_at)
user_listing     (user_id, listing_id, status [new|saved|contacted|rejected], notes)
```
